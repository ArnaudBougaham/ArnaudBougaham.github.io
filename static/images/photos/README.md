# Photos Directory

Place your personal photos here:

## Required Photos

1. **profile.jpg** or **profile.png** - Your main profile photo (recommended: 400x400px or larger, square format)
   - This will be used on the homepage/about section

2. **hero.jpg** or **hero.png** - Optional hero/banner image (recommended: 1920x600px or similar wide format)
   - For a banner/header image if your theme supports it

3. **research.jpg** or **research.png** - Optional research/workspace photo
   - Can be used in the publications or about section

## Image Guidelines

- **Format**: JPG or PNG
- **Profile Photo**: Square format (1:1 ratio) works best, minimum 400x400px
- **File Size**: Keep images optimized (under 500KB for web)
- **Naming**: Use lowercase with hyphens (e.g., `profile-photo.jpg`)

## Where Photos Are Used

- Profile photo: Referenced in `content/_index.md` and `config.toml`
- The Hugo theme will automatically style and display these images

## Quick Tips

- Use a professional headshot for the profile photo
- Ensure good lighting and clear background
- Consider using tools like TinyPNG to compress images before uploading
